# Política de Privacidad

Este es un documento de ejemplo para la web ficticia "Casa rural de pruebas".

## Responsable del tratamiento
- Titular: Casa rural de pruebas
- Contacto: info@casaruralpruebas.com

## Datos recopilados
- Datos enviados mediante el formulario o correo de contacto.
- Datos técnicos básicos de navegación (p. ej., IP y tipo de navegador).

## Finalidad
- Responder consultas y gestionar solicitudes de información.
- Mejorar la experiencia de usuario en el sitio web.

## Derechos
Puedes solicitar acceso, rectificación o eliminación de datos escribiendo al correo de contacto.
